# 자재 판매

충주공장 자재 판매 단가 업무 도구입니다. 브라우저에서 엑셀 파일을 올려 처리하며, 파일은 서버로 전송되지 않습니다.

## 메뉴
- **단가 점검**: 수불집계(ERP > 자재유형별수불집계 > 자재매출)와 주거래단가(Tableau 충주공장 > 메뉴_부서별 대시보드 (구매팀) > 충주공장 자재별 주거래단가)를 올리면, 계정대체 단가보다 낮게 판매된 자재·거래처를 찾아 단가 일괄처리 양식(.xls)으로 내려받습니다. FC1/FC2 사업장별, 담당자별 확인과 다운로드를 지원합니다.
- **단가 변경**: 준비 중

## 계정대체 단가
- 주거래단가 100원 이상: ROUNDUP(주거래단가 × 1.03, -1)
- 주거래단가 100원 미만: ROUNDUP(주거래단가 × 1.03, 0)

## 구성
- `index.html`: 도구 전체 (엑셀 처리 라이브러리, 거래처코드, 업체별 담당자 기본 목록 포함)
